# src

Código fuente de la aplicación del proyecto derivado.

- **Pertenece aquí:** código de producción organizado según [components.md](../docs/04-architecture/components.md).
- **No pertenece aquí:** tests (`tests/`), infraestructura (`infra/`), scripts (`scripts/`), documentación (`docs/`) ni código de un `SPIKE` sin work item propio.
- Todo cambio se origina en un work item registrado en [05-plans/index.md](../docs/05-plans/index.md).

La plantilla no incluye código ni impone lenguaje o framework.
