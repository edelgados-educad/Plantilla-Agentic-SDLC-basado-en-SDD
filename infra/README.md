# infra

Infraestructura como código del proyecto derivado: entornos, redes, permisos y pipelines de despliegue.

- **Pertenece aquí:** definiciones declarativas que materializan [deployment.md](../docs/04-architecture/deployment.md) y [environments.md](../docs/07-operations/environments.md).
- **No pertenece aquí:** secretos o credenciales, código de aplicación ni procedimientos (van en `docs/07-operations/`).
- Todo cambio aquí activa Security Review ([work-types.md](../docs/00-governance/work-types.md#applicability-triggers)).

La plantilla no selecciona cloud ni herramienta de infraestructura.
