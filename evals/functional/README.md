# Functional Evals

Evals de calidad funcional medible con datasets y umbrales (p. ej., precisión de búsqueda, clasificación o cálculo con tolerancia).

- **Pertenece aquí:** evals de AC con `Verification Type: eval` cuyo resultado no es binario.
- **No pertenece aquí:** comportamiento determinista (va en `tests/`) ni casos de seguridad o IA (`security/`, `ai/`).
- Formato mínimo en [evals/README.md](../README.md).
