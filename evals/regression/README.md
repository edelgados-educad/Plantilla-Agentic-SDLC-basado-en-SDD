# Regression Evals

Casos derivados de defectos e incidentes pasados que no deben reaparecer, cuando su verificación requiere dataset o métrica.

- **Pertenece aquí:** casos originados en `BUG`, `HOTFIX` o `INC-XXX`, con enlace a su origen.
- **No pertenece aquí:** regression tests deterministas (van en la carpeta de `tests/` que corresponda).
- Formato mínimo en [evals/README.md](../README.md). Origen y aprendizaje en el [Feedback Flywheel](../../docs/08-learning/README.md).
