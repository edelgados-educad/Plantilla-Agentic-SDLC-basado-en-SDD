# Security Evals

Casos adversariales que miden la resistencia del sistema: abuso de funcionalidades, inyección, escalamiento de privilegios y fuga de datos.

- **Pertenece aquí:** datasets de ataque y su scoring, vinculados a [security-checks.md](../../docs/06-quality/security-checks.md).
- **No pertenece aquí:** secretos reales, datos personales reales ni exploits contra sistemas de terceros.
- Formato mínimo en [evals/README.md](../README.md).
