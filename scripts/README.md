# scripts

Automatizaciones de soporte: build, verificación local, utilidades de desarrollo y, a partir de V2, validadores del harness.

- **Pertenece aquí:** scripts reproducibles y sin secretos, invocables por humanos, agentes y CI; cada uno documenta propósito y uso.
- **No pertenece aquí:** lógica de negocio (`src/`), infraestructura (`infra/`) ni datos sensibles.
- Un script que actúa como feedback sensor se registra en [feedback-sensors.md](../docs/06-quality/feedback-sensors.md).

En V1 la plantilla no incluye scripts.
