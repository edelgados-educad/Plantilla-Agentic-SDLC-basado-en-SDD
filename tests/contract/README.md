# Contract Tests

Pruebas de compatibilidad entre productores y consumidores de los contratos definidos en `contracts/` de cada spec.

- **Pertenece aquí:** verificaciones de schemas, formatos, eventos e interfaces públicas o entre componentes.
- **No pertenece aquí:** lógica de negocio (`unit/`) ni flujos completos (`integration/`).
- Obligatorias cuando aplica un Contracts trigger ([work-types.md](../../docs/00-governance/work-types.md#applicability-triggers)).
