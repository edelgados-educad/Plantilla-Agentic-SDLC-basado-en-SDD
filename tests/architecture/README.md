# Architecture Tests

Verificaciones automáticas de las reglas `AR-XXX` con `Automated: Yes` en [architecture-rules.md](../../docs/06-quality/architecture-rules.md).

- **Pertenece aquí:** dirección de dependencias, ausencia de ciclos, límites entre componentes y convenciones verificables.
- **No pertenece aquí:** pruebas de comportamiento funcional (`unit/`, `integration/`).
- Cada test indica en su nombre o metadato el ID de la regla que verifica.
