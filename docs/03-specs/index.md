# Specifications Index

**Covers:** catálogo de especificaciones de comportamiento.
**Delegates:** registro de ejecución de trabajos de cualquier tipo a [05-plans/index.md](../05-plans/index.md).

Una spec se crea copiando [_template/](_template/spec.md) a `docs/03-specs/[WORK_ID]-[SLUG]/`, solo para `FEATURE` y `CHANGE` grande ([Artifacts by Work Type](../00-governance/work-types.md#artifacts-by-work-type)). `Status` usa los valores definidos en la plantilla de spec.

| ID | Name | Status | Owner | Spec |
|---|---|---|---|---|

Ejemplo de fila: `| FEAT-001 | [FEATURE_NAME] | Draft | [OWNER] | [spec](FEAT-001-[SLUG]/spec.md) |`
