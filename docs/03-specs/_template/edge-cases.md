## Checklist

Categorías a evaluar antes del Spec Gate:

- [ ] Valores límite, vacíos, nulos y formatos inválidos
- [ ] Duplicados, concurrencia y reintentos
- [ ] Permisos insuficientes o sesión expirada
- [ ] Fallo, lentitud o respuesta inesperada de dependencias
- [ ] Volúmenes altos y paginación
- [ ] Zonas horarias, fechas y configuración regional
- [ ] Procesos interrumpidos o estados intermedios
