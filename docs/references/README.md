# References

Material fuente entregado por stakeholders u otros equipos: referencias visuales, manuales de marca, reglas de despliegue de otros sistemas, normativa y documentos del negocio.

- **Pertenece aquí:** el archivo original o, si es sensible o pesado, solo su enlace con control de acceso (p. ej., SharePoint o Confluence).
- **No pertenece aquí:** datos personales, credenciales ni documentos confidenciales sin control de acceso.
- **Regla:** cada referencia relevante se resume en texto en el documento que la usa ([constraints.md](../01-discovery/constraints.md), NFR, la spec, [integrations.md](../04-architecture/integrations.md) o [deployment.md](../07-operations/deployment.md)), citando su ID. Lo extraído entra como `Proposed` u `Open Question` hasta que el owner lo confirme.

|---|---|---|---|---|---|---|

`Type`: `Visual`, `Deployment`, `Regulation`, `Business` o `Technical`. `Classification`: valores de [data-model.md](../04-architecture/data-model.md).
