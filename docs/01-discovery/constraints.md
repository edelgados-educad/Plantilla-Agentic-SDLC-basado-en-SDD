# Constraints

Status: Draft · Owner: [OWNER]

Restricciones no negociables que limitan las soluciones posibles. Se completan en ASSESS y alimentan el [Assessment Gate](../00-governance/quality-gates.md#assessment-gate).

| Type | Constraint | Source | Impact |
|---|---|---|---|

`Type` toma uno de los valores de la tabla siguiente.

## Guiding Questions

| Type | Question |
|---|---|
| Technical | ¿Qué lenguajes, plataformas, versiones o estándares son obligatorios o están prohibidos? |
| Regulatory | ¿Qué normativa aplica (p. ej., protección de datos personales como la Ley 29733 en Perú, normativa sectorial)? |
| Budget | ¿Cuál es el presupuesto para desarrollo, licencias e infraestructura? |
| Time | ¿Qué fechas o hitos son fijos y por qué? |
| Security | ¿Qué políticas de seguridad, clasificación de datos o auditoría deben cumplirse? |
| Infrastructure | ¿Dónde debe ejecutarse la solución? ¿Qué entornos y capacidad existen? |
| Integrations | ¿Con qué sistemas debe integrarse y bajo qué condiciones (APIs, ventanas, cuotas)? |
