# ADR Index

Registro de Architecture Decision Records. Un ADR se crea copiando [_template.md](_template.md) a `docs/04-architecture/adr/ADR-XXX-[SLUG].md`, con numeración secuencial nunca reutilizada.

Se requiere ADR para cambios arquitectónicos relevantes ([Architecture Principles](../../00-governance/constitution.md#architecture-principles)), cambios de Project Profile, decisiones irreversibles y cambios al harness arquitectónicamente significativos.

| ID | Title | Status | Date |
|---|---|---|---|

Estados: `Proposed`, `Accepted`, `Deprecated`, `Superseded by ADR-XXX`. Un ADR `Accepted` no se reescribe: se reemplaza con uno nuevo.
