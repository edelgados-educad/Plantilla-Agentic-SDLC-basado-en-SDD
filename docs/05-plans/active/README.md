# active

Carpetas de trabajos en ejecución (`[WORK_ID]-[SLUG]/`), creadas en CLASSIFY copiando desde [_template/](../_template/plan.md) solo los archivos que indica [Artifacts by Work Type](../../00-governance/work-types.md#artifacts-by-work-type).

- **Pertenece aquí:** artefactos de trabajos en estado `Planned`, `Active` o `Blocked` en [index.md](../index.md).
- **No pertenece aquí:** specs (`docs/03-specs/`), código ni trabajos cerrados (van a `completed/`).
