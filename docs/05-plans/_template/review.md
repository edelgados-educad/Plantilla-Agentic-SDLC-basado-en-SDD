# [WORK_ID] — Review

Hallazgos de Reviewer y Security. Estados: `Open`, `Resolved`, `Accepted`. No se aprueba con `BLOCKER` o `HIGH` en `Open`. Un `BLOCKER` solo se cierra como `Resolved`; un `HIGH` pasa a `Accepted` solo con aprobación humana registrada en `decisions.md` o `change-record.md`.

| Severity | Meaning |
|---|---|
| `BLOCKER` | Incumple spec, Constitution o contrato; rompe build, datos o seguridad. |
| `HIGH` | Defecto probable o riesgo significativo de correctness, seguridad o arquitectura. |
| `MEDIUM` | Afecta mantenibilidad, legibilidad o cobertura sin riesgo inmediato. |
| `LOW` | Problema menor y localizado. |
| `SUGGESTION` | Mejora opcional; no bloquea. |
