# completed

Carpetas de trabajos cerrados (`Done` o `Cancelled` en [index.md](../index.md)), movidas desde `active/` sin alterar su contenido.

- **Pertenece aquí:** el registro histórico y auditable de cada trabajo.
- **No pertenece aquí:** trabajos en curso ni ediciones posteriores al cierre; un cambio posterior es un nuevo work item.
- Antes de mover: Convergence Gate aprobado (o motivo de cancelación registrado) e `index.md` actualizado.
